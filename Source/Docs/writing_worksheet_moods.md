# List of thought labels and descriptions for thoughtdefs
Stages are listed in chronological order. 
stage numbering follows stage index, causing numbering to be inverse of chronological order for peak and resolution hediffs. 
when transfering to thoughtdef xml, follow stage numbering.
in some cases label and/or description will be identical between stages. for instance all LYS good resolution phases may have the label "LYS Afterglow" but the mood effect changes between stages
